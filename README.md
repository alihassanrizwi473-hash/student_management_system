# Student Management System 🎓
A Python-based Student Management System that manages student records using JSON file storage and basic data management operations.

## Project Overview
Student Management System is a Python-based application designed to manage student records. It uses JSON file storage to save and retrieve student information.

## Features
- Add new student records.
- View student information.
- Manage student records.
- Store data in a JSON file.
- Retrieve saved records.

## Technologies Used
- Python
- JSON

## Data Storage
Student records are stored in a JSON file, making it easy to save and access data.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the main Python file:

```bash
python main.py
```

## Project Purpose
This project was created to practice Python programming, file handling, JSON data storage, and basic student record management.
